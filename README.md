# AI Support Ticket Prioritizer

An intelligent web application that automatically classifies and prioritizes support tickets using AI technology.

## Features

- **Automatic Classification**: Categorizes tickets as SUPPORT, SALES, or GENERAL
- **Priority Assignment**: Assigns HIGH, MEDIUM, or LOW priority based on urgency
- **AI-Generated Replies**: Creates professional responses using Groq LLM
- **Clean UI**: Modern, responsive interface with color-coded badges
- **Real-time Processing**: Instant analysis with loading states

## Technology Stack

- **Backend**: Node.js + Express
- **AI Processing**: Groq SDK with Mixtral model
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with responsive design

## Setup Instructions

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Create a `.env` file in the root directory:
```
GROQ_API_KEY=your_actual_groq_api_key_here
PORT=3000
```

To get a Groq API key:
1. Visit [https://groq.com](https://groq.com)
2. Sign up for an account
3. Navigate to the API keys section
4. Copy your API key

### 3. Start the Server
```bash
# For development (with auto-restart)
npm run dev

# For production
npm start
```

### 4. Access the Application
Open your browser and navigate to:
```
http://localhost:3000
```

## Usage

1. Enter a support ticket message in the text area
2. Click "Process Ticket" or press Enter
3. View the analysis results:
   - **Category Badge**: Shows the ticket category (SUPPORT/SALES/GENERAL)
   - **Priority Badge**: Color-coded priority (Red=High, Yellow=Medium, Green=Low)
   - **AI Reply**: Professional response generated by AI
4. Click "Process Another Ticket" to analyze additional messages

## API Endpoints

### POST /process
Processes a support ticket and returns classification and AI-generated reply.

**Request Body:**
```json
{
  "message": "Your support ticket message here"
}
```

**Response:**
```json
{
  "success": true,
  "data": {
    "category": "SUPPORT",
    "priority": "HIGH",
    "aiReply": "Generated professional response..."
  }
}
```

### GET /health
Health check endpoint to verify server status.

## Classification Logic

### Priority Levels
- **HIGH**: Login failures, payment issues, account access problems, emergencies
- **MEDIUM**: Inquiries, follow-ups, general questions, how-to requests
- **LOW**: General information, feedback, non-urgent queries

### Categories
- **SUPPORT**: Technical issues, bugs, errors, broken functionality
- **SALES**: Pricing, subscriptions, upgrades, purchase inquiries
- **GENERAL**: General questions, feedback, miscellaneous
